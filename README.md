# ✝️ RCCGLSC Website - Abuja | [rccglscabuja]

A modern, responsive landing website for **RCCG Living Seed Church (LSC), Abuja**, designed using **Next.js**, **React**, and **Tailwind CSS**. This project emphasizes a beautiful user interface with dynamic scroll-based navigation, responsive mobile support, and a modular layout structure built for speed, accessibility, and future scalability.

> 🔗 **Live Repository**: [https://github.com/dialite/rccglscabuja](https://github.com/dialite/rccglscabuja)

## 🔍 Overview

**RCCGLSC Abuja** is an elegant web platform developed to provide a user-friendly and functional interface for church activities, showcasing:

- Ministry information
- Weekly and monthly event highlights
- Contact details and church values
- Seamless page navigation with scroll and route awareness

---

## ✨ Features

- 📜 Scroll-to-section navigation on homepage
- 🖥️ Fully responsive layout with dropdown menu for smaller screens
- 🎨 Themed styling using Tailwind CSS
- 🖼️ Optimized image rendering via `next/image`
- 📱 Mobile-first UX with intuitive navigation
- ⛪ Clean, faith-based UI and branding
